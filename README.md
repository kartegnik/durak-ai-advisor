# Durak AI Advisor

Экспериментальный помощник для 36-карточного подкидного и переводного дурака.
Он распознаёт состояние мобильной/браузерной игры по снимкам экрана, ведёт
память партии, проверяет допустимые ходы и показывает рекомендацию обученной
рекуррентной модели. Помощник ничего не нажимает и не управляет игрой.

## Возможности

- двухступенчатое распознавание карт: YOLO-локализатор и классификатор 36 классов;
- распознавание козырной масти, счётчика колоды и надписей `Беру`, `Бито`, `Пас`;
- память руки, стола, биты и карт, которые точно взял соперник;
- правила подкидного и переводного режима;
- recurrent PPO v3, обученная только на доступной игроку информации;
- необязательный information-set поиск по возможным скрытым раскладам;
- отдельные инструменты обучения, оценки и воспроизведения скриншотов.

Полные игровые скриншоты, логи, разметка и виртуальное окружение намеренно не
входят в репозиторий. Для запуска используются только небольшие обезличенные
числовые шаблоны и готовые веса.

## Установка

Требуется Python 3.10+ и Linux с X11. Для окна подсказки нужен Tk, а для захвата
экрана — `scrot` или ImageMagick:

```bash
sudo apt install python3-tk scrot
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

Исправленный игровой движок уже находится в каталоге `durakgame`, поэтому
устанавливать соседний форк отдельно не требуется.

## Живая подсказка

Запускайте помощника с начала новой партии:

```bash
python cv/scripts/live_advisor.py --capture --new-game
```

По умолчанию снимок создаётся каждые 0,5 секунды. В терминале помощник попросит
указать козырную масть. Её также можно передать сразу:

```bash
python cv/scripts/live_advisor.py --capture --new-game --trump пики
```

Полезные параметры:

- `--no-overlay` — вывод только в терминал;
- `--interval 1.0` — изменить интервал захвата;
- `--role attack` или `--role defense` — указать роль при запуске в середине партии;
- `--use-v2` — откатиться на предыдущую модель;
- `--search-ms 100 --search-simulations 32` — включить экспериментальный поиск.

Состояние партии хранится локально в `cv/logs/live_state.json`. При продолжении
той же партии не передавайте `--new-game`.

## Android (экспериментальный клиент)

В каталоге `android/` находится нативное приложение, которое получает кадры
через системный `MediaProjection`, обрабатывает их только в оперативной памяти
и показывает результат поверх игры. Оно не запрашивает доступ к файлам или
интернету и не сохраняет снимки экрана.

Текущая мобильная версия `0.3.1` распознаёт карты в руке и на столе, запоминает
состояние партии и показывает ход, выбранный исходной моделью v1 среди
допустимых по правилам. Козырь можно указать кнопками мастей поверх игры. Всё
вычисляется на телефоне; снимки экрана не сохраняются. Инструкции находятся в
`android/README.md`.

Для воспроизведения последовательности собственных кадров положите их в
`cv/data/raw_screenshots` с именами `game_0000.png`, `game_0001.png` и т. д.:

```bash
python cv/scripts/track_screenshots.py --start 0 --end 100 --trump S
```

## Модели

| Файл | Назначение |
| --- | --- |
| `cv/models/card_localizer.pt` | поиск карт внутри игрового окна |
| `cv/models/card_crop_classifier_v10.pt` | классификация ранга и масти |
| `durak_model_v2.pt` | резервная модель ходов |
| `durak_model_v3.pt` | основная recurrent PPO модель |

На независимой симуляционной оценке v3 набрала 96,825% очков против случайного
соперника, 70,825% против эвристики и 69,175% против v2. Эти числа относятся к
встроенному симулятору, а не к реальным игрокам. На 83 картах из 12 вручную
проверенных скриншотов классификатор показал 97,6% top-1 accuracy; выборка мала
и специфична для одного интерфейса игры.

Код `durak_v4` оставлен как исследовательский эксперимент с предсказанием
скрытых карт. Он не используется по умолчанию и его веса не публикуются как
готовая замена v3.

## Тесты

```bash
python -m unittest discover -v
```

Часть интеграционных CV-тестов использует локальный набор скриншотов. Основной
запуск от него не зависит: необходимые шаблоны экспортированы в `cv/assets`.

## Обучение

Основную модель можно обучать независимо, не перезаписывая выпущенные веса:

```bash
python train_v3.py --run-dir runs/my_v3 --episodes 30000
python evaluate_v3.py runs/my_v3/best.pt --games-per-seat 1000
```

Обучение распознавателя требует собственного набора изображений и YOLO-разметки;
он не распространяется вместе с кодом из соображений размера и приватности.

## Приватность и ограничения

- Настольный режим захвата может записывать снимки всего экрана в
  `cv/data/raw_screenshots`. Android-клиент обрабатывает кадры только в памяти.
  Перед передачей сохранённых настольных кадров проверьте личные данные.
- Распознавание и советы могут ошибаться. Всегда сверяйте показанную в окне руку
  и роль игрока.
- Автоматические клики намеренно не реализованы.
